# District Panel of Socio-Economic Indicators of Kazakhstan, 2015–2025
# Районная панель социально-экономических показателей Казахстана, 2015–2025

**Authors / Авторы:** Viktoriya Nikitenko, Polina Reimar

## Abstract / Аннотация

Территориальное экономическое неравенство в Казахстане традиционно исследуется на уровне областей, что скрывает значительную внутриобластную неоднородность. В данной работе представлен первый публичный панельный датасет социально-экономических показателей районов Казахстана за 2015–2025 годы, собранный на основе открытых данных информационно-аналитической системы «Талдау». Датасет охватывает 204 района и включает 117 показателей по различным блокам: демографии, рынку труда, экономической активности, цифровизации, человеческому капиталу и общественной безопасности. Для демонстрации аналитического потенциала данных проведена кластерная классификация районов, выявившая 4 устойчивых типа экономического развития. 

**Keywords / Ключевые слова:** Казахстан, районные данные, региональное развитие, панельные данные, социально-экономические показатели, кластеризация.
